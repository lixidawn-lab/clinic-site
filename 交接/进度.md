## 骨架现状（供后续批次参考）
- Astro 7.3 + TypeScript。`clinic-site/` 是独立 git 仓库，已在 Lixi Studio 主仓库的 `.gitignore` 中排除（做法同窗边有光）。
- 路由：`/en/`、`/zh/`，共用英文 slug：`/about/`、`/notes/`、`/appointments/`；`/` → `/en/`。
- 本地预览：`npm run dev` → http://localhost:4410/
- 预览站：https://clinic-site.lixi-dawn5.workers.dev（推送 `main` 后自动部署）。Cloudflare 现在默认把它建成 Worker（静态资源），不是 Pages 项目；对静态网站效果一样，`_redirects` 也照常生效。
- 推送：Claude Code 的自动权限检查会拦下 `git push`，目前由灵晞在终端执行推送命令。
- TBC 一律写成 `TBC:清单编号`（如 `TBC:3.2`），不带编号会构建失败。
- 预览站标签（TBC、「初稿 · 待确认」、「待涵倪审阅」、「待取得转载许可」）只由一个开关控制：没开收录时（预览站）显示，开了收录时（正式站）全部不出现；`PUBLIC_SHOW_PREVIEW_LABELS=true/false` 可以强制显示或隐藏（取代原来的 `PUBLIC_SHOW_TBC`）。`npm run check:production` 会按正式站方式构建并检查没有任何标签。
- 字体自托管（`fonts/README.md`）；星汉等宽在每次构建时按全站实际用字子集化。图片原图在 `交接/设计稿/`，压缩脚本 `scripts/build-images.mjs`。
- 内容读取统一走 `src/lib/content.ts`；文章正文放在 `src/content/notes/<slug>/zh.md`（英文正文以后放 `en.md`）。
