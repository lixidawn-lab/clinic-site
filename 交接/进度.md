## 需要灵晞操作（批次 3，一次做一步）
Code 不碰任何账号和密钥。每做完一步告诉 Code 一声。

1. **建 Sanity 项目**：打开 https://www.sanity.io/manage ，用 lixidawn-lab 相关的邮箱登录或注册 → 「Create new project」→ 名称填 `clinic-site` → 数据集（dataset）用默认的 `production`、公开（public）→ 不要选模板。建好后，把页面上的 **Project ID**（8 位左右的字母数字，不是密码）告诉 Code。
2. **让这台电脑登录 Sanity**：在终端运行下面这条命令，浏览器会打开，用同一个账号登录即可（登录信息只存在这台电脑上，Code 看不到密码）：
   `cd /Users/lany/Documents/Lixi-Studio/clinic-site/studio && npx sanity login`
3. （Code 做）把现有内容导入 Sanity，部署后台到 https://drlauharnni.sanity.studio ，推送网站。导入会写入 29 份资料：诊所资料、医生资料、4 篇文章（含正文）、5 项服务、8 条 FAQ、4 个「如何开始」步骤、5 个常见困扰标签、1 个来源网站。不会删除任何东西。
4. **Cloudflare 建构建触发链接**：Cloudflare → Workers & Pages → `clinic-site` → Settings → Build → **Deploy Hooks** → 名称填 `sanity-publish`，分支选 `main` → Create → 复制生成的网址。**这个网址等于一把钥匙，不要发给别人，也不用发给 Code。**
5. **Sanity 发布时通知 Cloudflare**：https://www.sanity.io/manage → 选 `clinic-site` → API → Webhooks → Create webhook：
   - Name：`Cloudflare 重新构建`；URL：粘贴第 4 步的网址；Dataset：`production`
   - Trigger on：勾 Create、Update、Delete
   - Filter：`_type in ["settings","doctor","note","service","faq","howWeBeginStep","concern","source"]`
   - HTTP method：`POST`；其他保持默认（不要勾「Trigger webhook when drafts are modified」）→ Save
6. **邀请涵倪**：同一个项目 → Members → Invite → 填涵倪的邮箱，角色按「等灵晞决定」第 1 项选。先用邀请链接自己试一次能不能登录。
7. **试一次**：在后台「诊所资料」随便改一个字（比如营业时间）→ 右下角「发布」→ 告诉 Code 时间，Code 记录网站多久更新，然后再改回来。
