## 做了什么
- **中文字体**：中文改用访客设备的系统字体，顺序是苹方 → 冬青黑体 → Noto Sans SC → 思源黑体 → 微软雅黑。星汉等宽的字体文件、子集化脚本、授权文件、3 个开发工具和构建步骤都已删除，构建命令恢复成普通的 `astro build`。英文 Poppins 和 Palanquin 不变。中文页面现在只下载几个英文小字体（用于数字和英文字母，每个 8–20 KB），不再下载中文字体。CLAUDE.md 的设计令牌已同步。
- **域名**：所有 canonical、hreflang、og:url、sitemap、JSON-LD 都改成 `https://clinic.bythewindow.org`，代码里已经没有 `example.com`。CLAUDE.md 新增「域名」一节，写明这个域名是临时的、为什么用子域名，以及开放收录时要关掉 workers.dev 地址。
- **绑定域名**：Code 原本打算在配置文件里写上域名，让 Cloudflare 部署时自动绑定（`bythewindow.org` 已经在 Cloudflare 上，`clinic` 这个子域名也还没被占用）。但这一步会改 DNS，被 Code 的权限检查挡下了，所以改成由灵晞操作，逐步说明已写进 `进度.md`。
- **网站图标**：用诊所 logo 生成了 16、32、180（苹果设备）、192、512 五种尺寸，以及 `favicon.ico`。16px 版去掉了细的心形线，只留躺椅（截图 5）。苹果设备的图标需要不透明的底色，Code 用了 logo 自己的浅绿 `#DCECC8` 铺满整个方块，这一点可以再调整。另外生成了 `site.webmanifest`。
- **分享卡片图**：每次构建时自动生成中英文两张，大小是 1200×630，每张约 46 KB（截图 1、2）。浅绿底，左边是圆角照片，右边是 logo、名字（Poppins 700，中文名用 Noto Sans SC 粗体）和一行深绿色文字。文章页暂时也用这两张。卡片上的文字转成了图形，不依赖构建电脑上装了什么字体。
- **sitemap 和 robots.txt**：`sitemap.xml` 列出中英文 16 个页面，每条都带对应的另一语言版本。正式站的 `robots.txt` 会指向 sitemap；预览站仍然是 `Disallow: /`。
- **正式站检查**：`npm run check:production` 新增 3 项检查：每页都有分享卡片图；canonical 不指向 example.com 或 workers.dev；sitemap 里的地址和页面的 canonical 一一对应。Code 故意改坏一份副本测试过，3 项都能查出问题。
- **规则统一**：CLAUDE.md 硬性规则 7 和 PRD 3.3 已改为「窗边有光的文章可以放全文，开头放来源卡片，canonical 指向窗边有光原文」，原来的冲突提示已删除。
- **《我需要看心理医生吗？》**：在 `notes.json` 里加了一条备注（`internalNote`，不在网站上显示），写明出处等涵倪确认，确认后按 `media` 标注来源。正文没改。
