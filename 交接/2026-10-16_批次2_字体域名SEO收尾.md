# 交接：批次 2（中文字体、域名、SEO 收尾、规则统一）

## 要做什么
1. **中文字体改用系统字体**（灵晞选了 B）：中文按 `"PingFang SC", "Hiragino Sans GB", "Noto Sans SC", "Source Han Sans SC", "Microsoft YaHei", sans-serif` 的顺序回退。不再下载星汉等宽，也不再做子集化：删除相关脚本、字体文件和 devDependencies，构建命令同步改回来。英文的 Poppins 和 Palanquin 不变。更新 CLAUDE.md 和设计令牌。
2. **域名**：预览站和正式站暂时都挂在窗边有光已购买的域名下，用子域名 **`clinic.bythewindow.org`**（不要用 `bythewindow.org/clinic` 这种子目录，原因见第 7 条）。
   - `SITE_URL=https://clinic.bythewindow.org`。canonical、hreflang、og:url、sitemap 和 JSON-LD 都改用这个地址，代码里不能再出现 `example.com`。
   - 在 Cloudflare 上把 Worker 绑定到这个自定义域名：给灵晞写操作步骤，或者如果 Code 有权限就直接用 wrangler 配好。绑定后仍然保持 noindex。
   - workers.dev 地址保留作为备用，加 noindex。
3. **SEO 收尾**：
   - **网站图标**：用诊所 logo 生成 32、180（Apple）、192 和 512 尺寸。16px 的版本只保留躺椅造型，去掉细心形线，否则太小看不清。另外生成 `site.webmanifest`。
   - **分享卡片图（og:image，1200×630）**：中英文各一张，构建时自动生成。浅绿底 `#DCECC8`，左侧是圆角医生照片，右侧是 logo、医生名字（Poppins 700）和一行「Psychiatrist in Melaka」或「马六甲精神科专科医生」（`#1B7A35`）。文章页暂时也用这两张。
   - **sitemap.xml**：包含中英文所有页面，每条都带 hreflang 对应关系。`robots.txt` 在正式站引用 sitemap，预览站仍然是 `Disallow: /`。
   - 正式站检查脚本 `check:production` 要加三项检查：每页都有 og:image；canonical 没有一条指向 example.com 或 workers.dev；sitemap 里的地址和页面的 canonical 一一对应。
4. **规则统一**（灵晞已决定）：CLAUDE.md 硬性规则 7 和 PRD 3.3 改为：「窗边有光的文章可以在诊所网站放全文，开头放来源卡片，canonical 指向窗边有光原文」，不再写「不复制」。
5. **首页中文介绍**：继续用涵倪的原文（已决定）。
6. **《我需要看心理医生吗？》**：在内容文件里记一条备注：开头写着「摘自：梦翔中学第31期」，原始出处等涵倪确认，确认后按 `media` 标注来源。这一批不改正文。
7. **写进 CLAUDE.md 的提醒**：域名是临时的。正式开放收录之前，要先决定是否换成诊所自己的域名。用子域名的原因：以后搬家只要整个子域名做 301 跳转，比子目录简单，也不会和窗边有光的页面混在一起。

## 为什么
星汉等宽每个汉字占 1.2 个字宽，中文显得松散，灵晞决定换掉。canonical、hreflang 和 sitemap 都需要真实域名才有意义。网站图标、分享卡片图和 sitemap 是上线前必须补齐的 SEO 项目。

## 怎样算做完
- `https://clinic.bythewindow.org/zh/` 能打开，显示最新版本，并且是 noindex。
- 全站找不到 `example.com`；中文页面不再下载任何中文字体文件。
- Lighthouse 手机端在正式站构建下：性能、无障碍、最佳做法、SEO 都 ≥ 95。
